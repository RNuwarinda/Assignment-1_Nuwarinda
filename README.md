# Assignment 1: Automobile Price EDA

This project explores the automobile dataset to identify vehicle attributes associated with price.

## Files

- [Executed analysis notebook](./Nuwarinda_Automobile_EDA.ipynb) — data cleaning, descriptive statistics, visual analysis, group comparisons, feature screening, and dealer recommendation.
- [Cleaned dataset](./Nuwarinda_Data.csv) — missing values imputed; no exact duplicate rows or remaining nulls.
- [Source dataset](./automobileEDA(2).csv) — input used by the notebook.

Open the notebook from this folder and run its cells from top to bottom. It uses pandas, NumPy, and Matplotlib.
